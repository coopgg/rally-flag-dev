Clan Admin (throwaway)

Edits the real Rally Flag clan on Bungie.net via POST GroupV2/{groupId}/EditGroup/. You must be signed in as a clan Founder or Admin. Not linked from anywhere in the site nav, noindexed, and not meant to survive to production — this is a one-off tool for making clan changes without hand-building the API call each time.
This talks to the live Bungie.net clan, not a sandbox. Every "Confirm & Submit" below is a real, immediate edit to the clan everyone sees. If the app's OAuth scopes don't include admin group access (bungie.net → your app → edit → scopes), the submit will fail with a permission error.
