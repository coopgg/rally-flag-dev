Privacy Policy

For the Rally Flag website and the RallyBot Discord bot.

Last updated: August 2026

RallyBot (Discord)

RallyBot posts Destiny 2 rotation info (the Distortion tracker and featured weekly raid/dungeon) to Discord, either when you run a slash command or on a fixed schedule. It's intentionally minimal:

  • No message content access. RallyBot doesn't request Discord's message content intent — it can't read the messages you send.
  • No stored user data. When you run /distortion or /thisweek, Discord's own API tells the bot who ran it and where, same as any bot — but RallyBot doesn't log, store, or reuse that. It computes an answer and replies. Nothing about you is written anywhere.
  • The only thing it stores is which rotation hour/week it last posted about, so it doesn't double-post after a restart — no personal or server data, just two numbers.
  • No third-party sharing. RallyBot doesn't send any data anywhere except Discord's own API, and it doesn't call Bungie's API either — its rotation data is computed locally from a fixed pattern.

To remove RallyBot's access entirely, remove it from your server via Server Settings → Integrations at any time.

rallyflag.gg (the website)

  • The site itself doesn't have a server or database — it's static pages plus client-side JavaScript.
  • Pages that show Destiny data (raids, dungeons, builds, etc.) call Bungie's public API directly from your browser using a shared, non-personal API key. No account or personal info is required to use them.
  • The optional "sign in with Bungie.net" feature on Vendors uses Bungie's own OAuth login to show your loadouts. The resulting access token is kept in your browser's sessionStorage only — it's never sent to us, because there's no "us" to send it to. It's cleared automatically when you close the tab.
  • We use Cloudflare Web Analytics to see aggregate traffic (page views, referrers, rough location by country). It's cookieless and doesn't fingerprint or track you individually — Cloudflare's own privacy policy covers exactly what it collects. We don't run any other analytics, tracking pixels, or advertising on the site.
