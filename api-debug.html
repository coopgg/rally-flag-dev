Weekly Milestones

Pulls Bungie's public GetPublicMilestones endpoint and resolves every milestone hash it returns: name/description from DestinyMilestoneDefinition, the "about" blurb from GetPublicMilestoneContent, plus any activities/modifiers/quests/vendors attached to it this week, all resolved to real names. Nothing filtered or categorized. The point is to see the whole picture and figure out which hashes map to Vanguard, Crucible, vendors, etc. so we know what to automate FEATURED_THIS_WEEK and future section pages from.

Vendors

DestinyVendorDefinition (name/icon/location) resolves fine for anyone with just an API key, confirmed below. Live sale data is different: Bungie's anonymous Vendors endpoint only ever returns Xûr, no matter which vendor you ask for, confirmed by testing directly, not assumed. Every other vendor needs a signed-in character context (OAuth) to see what they're actually selling this week.

Eververse (Tess Everis)

Prod already chased this down once, before this site had OAuth: Bungie's public/anonymous Vendors endpoint drops Tess entirely, confirmed via a 3-way diagnostic (full request, bare Vendors-only request, and her own definition fetched directly — she came back enabled:true, genuinely active, the endpoint just can't serve her). Matches Bungie's documented rule that a vendor gets dropped wholesale from the public endpoint if any part of it can't be computed identically for everyone. Prod ended up sourcing her from a third-party feed, eververse.report, instead — noted then as a stopgap "until this site has its own OAuth login."

That's now. This calls the authenticated, character-scoped Character/{id}/Vendors/?components=400,402 — untested territory, since it wasn't an option before. No hash is hardcoded or guessed: whatever resolves to "Tess Everis" or "Eververse" among every vendor live for the signed-in character gets its real hash surfaced here. Confirmed working — she showed up. Since her catalog is per-character (an already-owned item drops off that character's list even though another character could still buy it), this queries every character on the account and merges the results; anything that isn't universal across all of them gets tagged with which class(es) it actually showed up for. If she still doesn't turn up this way, eververse.report is the proven fallback.

Catalog below is grouped by whatever currency each item's own cost data resolves to (not hardcoded/assumed) — the Bright Dust rotation refreshes at daily reset, so what shows up here is only good until tomorrow's reset. Bungie's API generally can't carry real-money Silver costs at all (those purchases route through platform stores, not this endpoint), so items with no cost data get their own bucket rather than being labeled "free" — that bucket is most likely Silver items, worth confirming against what actually shows in-game.
